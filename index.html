Hubungkan GitHub

File dikirim langsung dari browsermu ke GitHub, jadi browsermu butuh Personal Access Token milikmu sendiri. Halaman ini tidak punya server, jadi tidak ada cara lain.

  1. Buka halaman token baru.
  2. Pilih Classic lalu centang scope repo. Kalau yang terbuka hanya fine-grained, isi: Repository access → pilih hanya tugaskuliah, lalu Permissions → Repository permissions → Contents: Read and write.
  3. Klik Generate token, lalu salin yang muncul (awalan ghp_ atau github_pat_). Halaman itu hanya menampilkannya sekali.
  4. Tempel di bawah, klik Simpan. Token hanya tinggal di browsermu.

Token ini boleh menulis ke repo-mu dan tersimpan di localStorage peramban ini. Jangan pernah menempelkannya di chat atau commit. Kalau perangkatnya dipakai orang lain, hapus token begitu selesai.
